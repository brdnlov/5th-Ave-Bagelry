# 5th Ave Bagelry Long Beach 🥯🏖️

A small web project built to help **5th Ave Bagelry**, a local bagel shop in Long Beach, CA, attract more customers online.

## About

This is a small landing page, that redirects users to delivery options the store has, as well as showcases the menu so new customers can get a better feel of the menu before stepping into the store.
